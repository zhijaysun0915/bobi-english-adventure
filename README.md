## 🌟 四大階段・12 大分級完整架構 (共 192 關)

點擊畫面頂部「**等級膠囊按鈕**（例如：`🎒 小學・中級 ▾`）」，即可隨時自由切換目標階段與等級，進度獨立保存：

### 🎒 一、小學階段 (Elementary School)
- **🌱 小學・初級 (1-2年級 / Pre-A1，共 16 關)**：  
  英文字母與自然發音、1-10 數字、彩虹顏色、可愛寵物、玩具箱、文具用品、晨間問候、身體五官與心情。
- **⭐ 小學・中級 (3-4年級 / A1，共 16 關)**：  
  校園日常、熱血棒球 (`bat, glove, home run`)、超音速噴射機 (`jet, pilot, sky`)、太空火箭、撞球推桿 (`cue stick, pocket`)、侏儸紀霸王龍 (`T-Rex, roar`)、極速超跑與機器人。
- **🔥 小學・高級 (5-6年級 / A1+，共 16 關)**：  
  現在進行式、過去式初探、形容詞比較級 (`faster than`)、星期與四季、少棒冠軍錦標賽、無人機空拍、世界旅行與未來職業。

### 🏫 二、國中階段 (Junior High School)
- **⚡ 國中・初級 (國一 / A2-，共 16 關)**：  
  國中基礎 1200 單、一般動詞與 Be 動詞、頻率副詞 (`always, usually, often`)、六大疑問詞、棒球隊團隊合作與航空升力原理。
- **🏆 國中・中級 (國二 / A2，共 16 關)**：

- **👑 國中・高級 (國三會考衝刺 / A2+，共 16 關)**：  
  關係代名詞 (`who, which, that, whose`)、名詞子句、間接問句、花費動詞辨析、會考長篇素養閱讀、圖表數據分析與恐龍演化史。

## 🎮 核心遊戲特色

1. **隨心自由切換 12 等級**：
   - 頂部一鍵開關彈窗，小學至大學無縫切換，各等級通關進度獨立記錄在瀏覽器本機。
2. **學習進度跨裝置遷移 (匯出 / 匯入 JSON 備份)**：
   - 設定視窗支援一鍵下載 `.json` 學習進度備份檔，並可在不同電腦、平板或手機隨時匯入還原通關紀錄、XP 與寶石。
3. **電腦端鍵盤快捷鍵 (`1`~`4` 與 `Enter`)**：
   - 選擇題與聽力測驗支援數字鍵 `1` ~ `4` 快速選答，並可按 `Enter` 鍵快速檢查答案或進入下一題。
4. **生動卡通泡泡音效 (純 Web Audio API)**：
   - 木質 Water Pop 點擊音、瑪利歐卡比升調星星通關音、生動彈簧 Boing 答錯提示音、全壘打勝利號角。
5. **連續答對 COMBO 系統**：
   - 連續答對 2 題、3 題、4 題以上觸發熱血全壘打與噴射機衝刺加速橫幅！
6. **真人美語標準發音 (Web Speech API)**：
   - 內建朗讀引擎，單字、句子、聽力測驗皆可無限次點擊小喇叭聆聽。
7. **愛心體力與快速補血機制**：
   - 起始 5 顆愛心，答錯扣心；若愛心耗盡，可進行「快速複習練習」答對 3 題立即補滿 5 顆愛心！
8. **專屬榮譽證書與一鍵列印 / 另存 PDF**：
   - 各等級完成第 16 關魔王考驗後，可輸入學生姓名頒發金牌榮譽證書，並支援「🖨️ 列印 / 另存為 PDF」高畫質排版輸出！
